[ 내부망용 엑셀 취합 도구 사용 안내 ]

1. index.html 실행 (더블 클릭)
2. 취합 방식 선택:
   - [전체 취합]: 여러 부서 엑셀 파일의 모든 행 데이터를 하나로 이어 붙임
   - [취합양식에서 작성 부분만 취합]: 배포된 서식에서 각 부서가 작성한 내용 및 추가 행을 원래 위치에 맞추어 취합
3. '취합할 폴더' 선택 (폴더 내 모든 엑셀 자동 인식)
4. '취합 시작' 버튼 클릭
5. 브라우저로 자동 생성된 취합 결과 엑셀 확인 (화면 하단 미처리 내역 확인)

※ 본 프로그램은 외부 서버 통신, 인터넷 연결, DB, Python 등이 일체 필요 없는 100% 브라우저 메모리 기반 오프라인 도구입니다.
※ 원본 파일은 절대 훼손되지 않으며, 사용자 개인정보나 파일 데이터가 외부로 전송되거나 로컬에 남지 않습니다.
