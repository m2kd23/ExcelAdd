# 내부망용 엑셀 취합 도구 - 시스템 설계서 및 사용자 매뉴얼

---

## 1. 시스템 개요 및 구성도 (System Architecture)

본 프로그램은 서버/DB/인터넷 없이 사용자 PC 브라우저 내부에서만 100% 동작하는 **오프라인 전용 엑셀 취합 도구**입니다.

```
[ 사용자 브라우저 (Chrome, Edge, Whale) ]
  ├── UI 계층 (index.html, HTML5/Vanilla CSS)
  ├── 코어 엔진 (JavaScript, Pure Memory Array Parsing)
  ├── 엑셀 엔진 (xlsx.full.min.js - 로컬 내장)
  └── 파일 I/O (FileReader API / XLSX.writeFile Blob 생성)

※ 외부 서버 통신 0건 (No WAS, No Python, No DB, No Fetch, No CDN)
```

---

## 2. 기능 분류 및 알고리즘 (Functional Breakdown)

### 1) [전체 취합] 모드 (단순 행 합치기)
- **자동 제목줄 감지 (detectHeaderRowIndex)**: 상단 배너나 공백행이 있어도 실제 표의 헤더를 자동 식별하여 상단 1회만 유지하고 데이터 행을 이어 붙임.
- **컬럼 자동 정렬**: 부서별 파일의 컬럼 순서가 달라도 컬럼명 기준으로 자동 매핑.

### 2) [취합양식에서 작성 부분만 취합] 모드 (지능형 매칭 & In-Place 행 삽입)
- **서식 자동 식별**: 마스터 파일이 없어도 대상 폴더의 첫 번째 파일 양식을 베이스로 자동 채택.
- **문맥 기반 제자리 행 삽입 (In-Place Insertion)**: 특정 부서가 중간에 행을 추가한 경우, 기존 행의 짝이 어긋나지 않도록 해당 부서의 작성 위치에 A~F열 전체 1개 행을 통째로 삽입.

### 3) 공통 관리 기능
- **폴더 일괄 자동 필터링**: `~$...` 임시 엑셀 파일 및 비엑셀 파일 자동 제외.
- **무결성 및 미처리 추적**: 셀 충돌이나 누락 발생 시 기존 데이터를 보존하고 화면 하단 및 엑셀 하단에 미처리 내역 기록.

## 3. 사용자 매뉴얼 (User Manual)

### 실행 방법
1. `index.html`을 더블 클릭하여 실행합니다.

### 취합 진행 단계
1. **취합 방식 선택**:
   - **`[전체 취합]`**: 여러 부서의 데이터 행을 아래로 쭉 합칠 때
   - **`[취합양식에서 작성 부분만 취합]`**: 배포 양식의 빈칸을 채우고 추가 행을 제자리에 맞출 때
2. **`[폴더 선택]`** 버튼을 눌러 취합할 파일들이 있는 폴더 지정
3. **`[취합 시작]`** 버튼 클릭 ➔ 브라우저 다운로드 폴더에 결과 엑셀 자동 저장!
